# 🎬 릴스·쇼츠 메이커

휴대폰만으로 인스타그램 릴스·유튜브 쇼츠용 세로(9:16) 영상을 만드는 웹앱(PWA)입니다.
**서버도 PC도 필요 없습니다.** 영상 인코딩까지 전부 휴대폰 브라우저 안에서 처리합니다.

## 사용법
1. 휴대폰 Chrome으로 앱 주소를 열고 메뉴 → **홈 화면에 추가**(앱처럼 설치, 오프라인 동작)
2. **＋ 새 영상 만들기**
   - 🤖 AI로 만들기: 주제만 적으면 대본·자막·해시태그까지 작성 (Gemini API 키 필요)
   - 📝 대본으로 만들기: 글을 붙여넣으면 문장마다 장면·자막 자동 생성
   - 🖼 사진·영상으로 만들기: 갤러리에서 여러 개 선택
3. 장면 편집(큰 자막·대사 자막·길이·움직임·영상 구간 자르기·나누기), 스타일(템플릿·자막 디자인·전환),
   오디오(내장 음악·내 음악 파일·AI 음성·내레이션 녹음)
   **🖼 이미지**: 장면마다 그림 설명(프롬프트)을 만들어 📤 보내기(ChatGPT·Gemini 앱으로 전달) 또는 📋 복사 → ChatGPT 등에 붙여넣어 그림 생성 →
   🖼 넣기(또는 여러 장 한꺼번에 넣기: 저장된 순서대로 장면에 들어감). 모든 장면에 이미지가 들어가면
   장면별 전환·화면 움직임·자막 효과가 그림 밝기·모양과 자막 내용에 맞춰 자동 추천·적용됩니다 (✨ 효과 추천으로 다시 적용).
   **🧑 캐릭터**(홈 화면): 콘셉트를 적으면 AI가 이름·외형·말투를 만들고, 📤 보내기로 ChatGPT·Gemini에 전신 그림을 주문해 넣으면
   단색 배경을 지워 저장합니다. "이 캐릭터로 영상"을 누르면 그 캐릭터 말투로 대본을 쓰고(지난 영상에 이어지는 다음 편도 가능),
   캐릭터는 장면 그림 안에 같은 생김새로 등장합니다 (📤 보내기 때 캐릭터 그림이 함께 넘어감).
   **🎬 모션**: 장면 그림을 넣은 뒤 🎬 움직이게 → 그림과 움직임 주문서가 Gemini·ChatGPT·Kling 등으로 함께 넘어가고,
   만든 영상을 🎞 영상 넣기로 넣으면 캐릭터가 실제로 움직이는 장면이 됩니다 (AI 음성 길이 유지, 짧으면 마지막 화면에서 멈춤).
   구석에 캐릭터 그림을 합성하는 방식도 스타일에서 켤 수 있습니다 (배경이 지워진 그림일 때).
4. **내보내기** → MP4 완성 → 인스타·유튜브로 바로 공유하거나 기기에 저장

## API 키 (선택 기능)
홈 화면 ⚙️ 설정에서 **Gemini API 키**를 넣으면 AI 대본과 AI 음성을 쓸 수 있습니다 (무료 등급).
Google AI Studio(aistudio.google.com) → "Get API key"에서 발급합니다.

- 키는 기기에만 저장되고 Google로만 직접 전송됩니다.
- 한 줄에 하나씩 여러 개를 넣을 수 있고, 한 키가 한도에 걸리면 자동으로 다음 키를 씁니다.
  한도는 Google 프로젝트 단위이므로 서로 다른 프로젝트에서 만든 키여야 효과가 있습니다.
- 키가 없어도 나머지 기능(편집·내장 음악·내보내기)은 모두 동작합니다.

## 안드로이드 앱(APK)
`android/`는 웹앱을 그대로 담는 WebView 껍데기입니다. 웹 파일이 APK 안에 들어가므로 인터넷 없이 실행되고,
뒤로가기·파일 선택·마이크·갤러리 저장·공유는 네이티브 쪽에서 처리합니다.

```
export ANDROID_HOME=<안드로이드 SDK 경로>
export SHORTS_KEYSTORE=<서명 키 파일> SHORTS_KEYSTORE_PASS=<비밀번호>   # 키 별칭: shorts
cd android && gradle assembleRelease      # → app/build/outputs/apk/release/app-release.apk
```
같은 서명 키로 빌드해야 기존 설치본 위에 덮어쓰기 업데이트가 됩니다 (키가 바뀌면 삭제 후 재설치 → 프로젝트 데이터 삭제).

## 적용 기술
| 기술 | 용도 |
|---|---|
| Canvas 2D 렌더 엔진 | 미리보기와 결과물이 동일한 프레임 합성 (켄번스, 자막 효과, 전환) |
| WebCodecs + mp4-muxer | 기기 내 H.264/AAC MP4 고속 인코딩 |
| MediaRecorder | WebCodecs 미지원 브라우저용 대체 내보내기, 내레이션 녹음 |
| Web Audio (OfflineAudioContext) | 배경음악·내레이션·클립 소리 믹싱 |
| Gemini API (구조화 출력·TTS) | AI 대본·자막·해시태그 생성, 장면별 AI 음성 |
| Web Audio 신시사이저 | 음원 파일 없이 내장 음악 5종을 즉석 생성 |
| IndexedDB | 프로젝트·미디어를 기기에 저장 (자동 저장) |
| Service Worker + Manifest | 설치형 PWA, 오프라인 실행 |
| Web Share API | 완성 영상을 인스타·유튜브 앱으로 바로 전달 |
| Screen Wake Lock | 내보내는 동안 화면 꺼짐 방지 |
| GitHub Actions + Pages | 푸시하면 자동 배포 (PC를 켜둘 필요 없음) |

## 배포 (최초 1회 설정)
저장소 **Settings → Pages → Source 를 "GitHub Actions"** 로 바꾸면, 기본 브랜치에 푸시할 때마다
`https://<계정>.github.io/reels-shorts-maker/` 로 자동 배포됩니다.

## 구조
- `index.html`, `css/style.css` — 화면
- `js/app.js` — 화면 흐름(홈·편집기·시트), 뒤로가기 처리
- `js/render.js` — 프레임 렌더·오디오 믹싱
- `js/exporter.js` — 영상 인코딩
- `js/ai.js` — AI 대본, AI 음성 (Gemini)
- `android/` — APK용 WebView 껍데기
- `js/music.js` — 내장 음악 생성
- `js/db.js` — 저장소
- `sw.js` — 오프라인 캐시 (배포 시 `VERSION` 올리기)

## 로컬 실행
`python3 -m http.server` 후 `http://localhost:8000`
